# Entrega 2 — Modelo relacional y normalización

Segunda entrega del proyecto Sistema de Gestión de Biblioteca Universitaria: el diseño de una base de datos para una plataforma que administra los recursos bibliográficos, los procesos de circulación y las políticas de préstamo en una red de bibliotecas multi-sede.

En esta entrega transformamos el modelo E-R de la primera entrega en un modelo relacional de 20 tablas con el tipo de dato de cada columna, y lo normalizamos hasta la quinta forma normal (5FN).
