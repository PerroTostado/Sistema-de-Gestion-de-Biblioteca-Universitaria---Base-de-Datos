# Sistema-de-Gestión-de-Biblioteca-Universitaria---Base-de-Datos
Sistema de base de datos para gestionar una biblioteca universitaria: títulos vs. ejemplares, circulación (préstamo, renovación, reserva), red multi-sede, catálogo, políticas y sanciones, recursos físicos/digitales y disponibilidad híbrida. Incluye análisis de tendencias y herramientas
